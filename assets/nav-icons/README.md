# Navigation badges

These 192 × 192 transparent PNGs are web-sized copies of the six original
`assets/*_icon.png` files supplied by the team. The originals are preserved.
CSS displays them at 42–80 px so the menus do not decode six 10,000 px images.

- Phoenix: the team and Renata identity
- Stomach: the project story
- DNA: engineering and laboratory work
- Microphone: human practices and communication
- Plant: education and growth response
- Eiffel tower: sponsors and the wider project community

Link labels, descriptions, and icon assignments live in `js/site-content.js`.
Both homepages and the reading pages use `js/navigation.js` and
`css/navigation.css`. All assets and interactions run locally.
